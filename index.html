Step 2

Give your agents a home

On your dev machine, or on a server that stays on.

Your machine. Your agents. Runs in Docker.

Two ways to install:

Install on your dev machine

Run this Bash command in a terminal on your development machine:

curl -fsSL https://agentsinthecloud.com/install.sh | bash -s -- --action install --access-mode localhost

macOS or Linux. On macOS, install and start Docker Desktop first. The installer opens AgentsInTheCloud locally. Your agents can work while your machine is awake.

This command downloads and runs the installer. Read it first ↗

Install on a server

Use a Mac mini in your closet, or a VPS from Hetzner or DigitalOcean. On that machine, run this Bash command:

curl -fsSL https://agentsinthecloud.com/install.sh | bash -s -- --action install --access-mode tailscale

On a VPS, connect over SSH first. On a Mac mini, start Docker Desktop first. Follow the installer to sign in to Tailscale, then open the private address it prints. Agents keep working while the server stays on.
